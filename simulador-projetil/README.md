# Simulador de Projétil

Simulação do movimento de projéteis (lançamento oblíquo), feita para
alunos do ensino médio.

Demo: https://SEU-USUARIO.github.io/portfolio/simulador-projetil/

## O que faz
- Mostra a trajetória do projétil em um gráfico/animação.
- Permite mudar [velocidade inicial, ângulo de lançamento, gravidade — ajuste para o que o seu simulador realmente tem].
- [Mostra alcance, altura máxima e tempo de voo, se for o caso.]

## Por que fiz
É um material de apoio para o ensino de física: o aluno mexe nos valores
e vê o que acontece com o movimento, em vez de só ler as fórmulas.

## Tecnologias
Python, VPython, HTML [e JavaScript, se usou]

## Como rodar
Abra o arquivo `index.html` no navegador, ou acesse a demo pelo link acima.
